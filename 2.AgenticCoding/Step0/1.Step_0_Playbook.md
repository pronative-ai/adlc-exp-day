## Working with Agentic Coding Agent - OpenCode

### Step 1: Review or understand the Requirements

We need users to convert between currencies in real time — pick two currencies, enter an amount, see the converted value instantly. Rates should come from a live external source, but we can't hammer that API on every keystroke or every container restart under Azure's scaling. We also need every conversion logged for compliance — an auditor should be able to pull a customer's last 10 conversions on request.

### Step 2: Prepare your own PROMPT or INTENT for the Agentic Coding Agent
* Build this. However you normally would

### Step 3: Open your OpenCode Agentic Coding agent from VS Code Terminal, and paste your prompt to kick off the coding workflow:

* Open the `makefile` in root folder
* Update placeholder for participant with your enrolment id  (e.g. replace <ENROLLMENT_ID> with ST-2608-adlc101) and save the file
* run the command `make run` from VS Code terminal
* Paste and run your `PROMPT` or `INTENT` from Step 2
