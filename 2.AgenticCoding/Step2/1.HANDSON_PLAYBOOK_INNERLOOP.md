## WORKING WITH AGENTIC CODING AGENT (OpenCode)

### Step 1: UNDERSTAND Structured Business Intent

If you want to modify the business requirements for your hands-on session, you can open `input-spec-agent.md` and customize certain sections.

However, you must follow these strict guidelines:

* **What you CAN customize:** You are free to modify **Business Intent Title, Business Idea, Persona, User Need** to change the app idea, or  your custom data requirements.

* **What you MUST leave AS IS:** Do **not** modify **Known Constraints**. The agent requires these exact rules to develop cosmos services, utilzie environment variables and safely push your scaffolding/Pull Requests to GitHub.


## Step 2: PLAN - Using pronative.ai ADLC Spec Agent

* In VS Code Terminal enter command `opencode` to open a new session.
* Type `/agents` in the chat panel.
* Enter `pronative.ai Spec Agent` in the search box.
* Scroll through the agent list to select `spec-agent`.
* Press enter to confirm your selection.

* Paste the below prompt to kick off the spec agent (a markdown file appears under the spec folder once processing is complete).

```text
Process `intent\input-spec-agent.md` file.

```

## Step 3: IMPLEMENT - Using Agentic Coding Agent (OpenCode) with pronative.ai Custom Model (GPT-5.4-nano)

* After step 1 is finished, then type `/agents`.
* Enter `build` in the search box to get back from the spec-agent
* Scroll through the agent list to select `Build`.
* Type `/models` in the chat panel.
* Enter `pronative` in the search box.
* Scroll through the agent list to select `pronative.ai GPT Nano`.
* Press enter to confirm your selection.
* Paste the below prompt below to kick off the agentic coding agent to implement the spec.

```text
Implement the plan from spec md file under `spec` folder.

```
