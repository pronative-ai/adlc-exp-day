## 🔧 Step 1: Fork and Clone the Repo Locally

### 🍴 Forking the Repository
1. Log in to your **GitHub** account.
2. Navigate to the **pronative.ai** repository URL: `https://github.com/pronative-ai/adlc-exp-day-step2`.
3. Click the <kbd>Fork</kbd> button in the top-right corner of the GitHub page.

### 📥 Cloning to Your Machine
Open your standard **Command Prompt** (CMD) and execute the following commands sequentially to clone and open the project:

```bash
# Clone your personal fork of the repository
git clone https://github.com/<your-github-username>/adlc-exp-day-step2.git

# Move into the project directory
cd adlc-exp-day-step2

# Open the project inside Visual Studio Code
code .
```

## 🤖 WORKING WITH AGENTIC CODING AGENT (OpenCode)

### 🧠 Step 1: UNDERSTAND Structured Business Intent

If you want to modify the business requirements for your hands-on session, open the file `intent\input-spec-agent.md` to customize your application logic. 

You must follow these strict operational rules:

* **✅ What you CAN customize:** You are completely free to modify the **Business Intent Title**, **Business Idea**, **Persona**, and **User Need** sections to build your own custom app idea or data schema.
* **🛑 What you MUST leave AS IS:** Do **not** modify the **Known Constraints** section. The AI agent strictly requires these exact rules to build Cosmos services, parse system environment variables, and safely automate your GitHub Pull Requests.

---

### 📝 Step 2: PLAN - Using pronative.ai ADLC Spec Agent

Follow these UI steps inside VS Code to initialize the architectural planning stage:

1. **Start OpenCode:** Open your VS Code Terminal, type `opencode`, and press <kbd>Enter</kbd> to launch the session.
2. **Open Agents Menu:** Type `/agents` in the chat panel overlay.
3. **Search for Agent:** Enter `pronative.ai Spec Agent` into the search field.
4. **Select Agent:** Scroll through the filtered list and highlight `Spec-Agent`.
5. **Confirm Selection:** Press <kbd>Enter</kbd> to bind the agent to your active session.
6. **Execute Planning:** Copy and paste the exact prompt below into the chat panel to generate your architectural spec:

```text
Process `intent\input-spec-agent.md` file.
```

> [!TIP]
> Once processing is finalized, a brand new Markdown specification file will automatically appear under your workspace `spec/` folder.

---

### 🛠️ Step 3: IMPLEMENT - Switch to Build Agent & Custom Model

> [!IMPORTANT]
> **Do not skip this step!** You must explicitly switch your active agent from the **Spec-Agent** back to the native **Build** agent, and activate the custom `pronative.ai GPT Nano` model before running the implementation prompt.

#### 1️⃣ Switch back to the OpenCode Native Build Agent
* **Open Agents Menu:** Type `/agents` in the chat panel.
* **Search for Build:** Enter `build` in the search box to exit the spec-agent context.
* **Select Agent:** Scroll through the agent list and select the native `Build` agent.
* **Confirm:** Press <kbd>Enter</kbd> to activate the Agentic Coding Agent.

#### 2️⃣ Load the Custom Model (`pronative.ai GPT Nano`)
* **Open Models Menu:** Type `/models` in the chat panel.
* **Search for Model:** Enter `pronative` in the search box.
* **Select Custom Model:** Scroll through the model list and select `pronative.ai GPT Nano`.
* **Confirm:** Press <kbd>Enter</kbd> to lock in the custom code-generation model.

#### 3️⃣ Execute Code Generation
* **Run Prompt:** Paste the exact prompt below into the chat panel to instruct the Build agent to compile and execute your newly generated architecture plan:

```text
Implement the plan from spec md file under `spec` folder.
```
